# Security Policy

## Supported Website

This security policy applies to the current version of my portfolio website at https://henokmolla.com.

## Reporting a Vulnerability

I take the security of my website seriously and appreciate responsible security reporting.

If you discover a potential security vulnerability, please report it privately using GitHub's **Report a vulnerability** feature under the repository's Security section.

Please include:
- A description of the vulnerability
- Steps to reproduce the issue
- The affected page or feature
- The potential security impact

Please do not report security vulnerabilities through public GitHub issues.

## Responsible Disclosure

Please avoid accessing private information, disrupting the website, or performing destructive testing.

I will review security reports and work to address confirmed vulnerabilities as appropriate.

Thank you for helping keep this project secure.
